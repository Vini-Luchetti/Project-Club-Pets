## O projeto

O **Clube do Corvo** é um portal web interativo com estética *creepy-cute* — pense Tim Burton encontrando um catálogo de adoção de bichinhos. Foi desenvolvido como presente para Helena (a Pinguinho), com um objetivo duplo: proporcionar uma experiência lúdica e segura com tecnologia, e introduzir conceitos básicos de programação de forma acessível.

> ⚠️ **Uso supervisionado:** Recomendado sempre com acompanhamento de um Guardião.

---

## Funcionalidades

### 🔮 O Caldeirão de Prompts
Gerador de prompts estruturados para IAs de imagem. A criança seleciona "ingredientes" em listas temáticas, o Caldeirão combina tudo em uma Fórmula Mística pronta para usar em geradores como Midjourney, DALL-E ou Stable Diffusion.

### 🐾 Ritual de Adoção
Cada pet tem uma ficha mística com personalidade, habilidades e requisitos de cuidado. A adoção passa por um processo temático — nada de clique e pronto.

### 🎭 Quiz de Afinidade
Descubra sua afinidade mágica antes de encontrar o pet ideal. O quiz adapta as sugestões baseado nas respostas.

### 🐦 Torre dos Corvos Correios
Sistema de mensagens com animações exclusivas em CSS — corvos voando incluso.

### 🪙 Penas de Cristal
Sistema de créditos interno para gamificar a experiência de exploração do portal.

## Tecnologias

| Camada | Tecnologia | Para quê |
|---|---|---|
| Estrutura | HTML5 semântico | Páginas de adoção e rituais |
| Visual | CSS3 + animações | Tema creepy-cute, corvo voando, efeitos neon |
| Lógica | JavaScript Vanilla | Quiz, LocalStorage, Caldeirão |
| Versionamento | Git / GitHub | Controle de evolução do projeto |

Sem frameworks. Sem dependências externas. HTML + CSS + JS puro — proposital, para fins educativos.

## Como rodar

Não precisa de servidor. Abra direto no navegador:

```bash
# Clone o repositório
git clone https://github.com/Vini-Luchetti/Project-Club-Pets.git

# Entre na pasta e abra o index.html no navegador
cd Project-Club-Pets
# Windows:
start index.html
# Mac:
open index.html
```

Ou use o [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) no VSCode para hot reload durante edição.
